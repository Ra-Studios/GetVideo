# GetVideo

A free Android application by **RA Studios**, an independent company building free applications. Save publicly accessible video, audio and available subtitles for offline use.

**[Visit the GetVideo website](https://ra-studios.github.io/GetVideo/)** · **[Download the latest APK](https://github.com/Ra-Studios/GetVideo/releases/latest)** · **[Support RA Studios](https://www.rastudios.site/donate)**

## What you can do

- Choose available video qualities or audio-only downloads.
- Trim a clip using start and end times.
- Save available subtitles with a video or as a separate SRT file.
- Organize, play and share downloaded files through the Media Vault.
- Follow background downloads with progress notifications.
- Check for new releases in Settings; version 1.0.3 and newer also support update prompts.

## Install on Android

1. Visit the website and choose **Download for Android**, or open the latest GitHub release.
2. Download the `.apk` file under **Assets**. Android 7.0 or newer is required.
3. Open the APK and approve installation from your browser or file manager if Android asks. Install over an existing GetVideo app to preserve your Vault and settings.
4. Paste a supported public media link, choose **Fetch**, then select your format. Completed Android downloads save to **Downloads / GetVideo**.

Available quality, captions and speed depend on the original upload, source platform and connection. Use GetVideo only for content you own, have permission to download, or are otherwise allowed to save.
